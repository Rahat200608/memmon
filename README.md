# memmon

Универсальный монитор памяти и CPU для любой Python-программы: Telegram-бот, сайт, скрипт, сервис.
Подключается одной строкой (или вообще без правки кода) и пишет в CSV-файл, как программа расходует ресурсы со временем.

Название: **mem**ory **mon**itor. Его можно сменить на любое другое (см. раздел «Переименование»).

## Зачем это нужно

- Найти утечку памяти: видно, растёт ли потребление непрерывно или стабилизируется.
- Выбрать хостинг: пиковое значение RAM показывает, какой минимальный тариф потребуется.
- Оценить влияние клиентов: колонка `connections` показывает число соединений в каждый момент, а время в логе можно сопоставить с отчётом нагрузочного теста.
- Измерить чужой проект без правки его кода: `python -m memmon script.py`.

## Требования

- Python 3.8 или новее
- Библиотека `psutil` (ставится автоматически)
- Работает на Windows, Linux и macOS

## Установка

С GitHub (публичный репозиторий):

```
pip install git+https://github.com/Rahat200608/memmon.git
```

Для приватного репозитория понадобится токен доступа GitHub.

## Способы использования

Команды из этой таблицы пишутся в разных местах: строки Python идут в файл `.py`, остальное в терминал.

| Что нужно | Где писать | Что писать |
|---|---|---|
| Запустить чужую программу под замером, не трогая её код | терминал | `python -m memmon main.py` |
| Включить монитор из кода одной строкой | начало `.py` файла | `import memmon.auto` |
| Включить с настройками | `.py` файл | `import memmon` и `memmon.start(interval=5)` |

`import memmon.auto` ставь первой строкой программы, чтобы замер шёл с самого старта.

## Что делает каждый файл

```
memmon/
├── pyproject.toml
├── README.md
└── memmon/
    ├── __init__.py
    ├── __main__.py
    └── auto.py
```

| Файл | Назначение |
|---|---|
| `pyproject.toml` | Описание пакета для pip: название, версия, зависимость от `psutil`. Благодаря ему работает `pip install`. |
| `memmon/__init__.py` | Основная логика. Функция `start()` запускает фоновый поток, который раз в заданный интервал замеряет память, CPU, потоки и соединения и дописывает строку в CSV. Повторный вызов `start()` ничего не делает. |
| `memmon/auto.py` | Сокращение. При `import memmon.auto` Python выполняет файл, и монитор запускается сам с настройками по умолчанию. |
| `memmon/__main__.py` | Позволяет запускать чужой скрипт через `python -m memmon script.py [аргументы]`. Запускает монитор, затем выполняет указанный скрипт как обычно. |

## Что пишется в отчёт

Файл `memmon_<PID>.csv` создаётся рядом с программой. Разделитель `;`, открывается в Excel.

| Колонка | Смысл |
|---|---|
| `time` | Время замера |
| `rss_mb` | Занятая память (RSS) в МБ, включая дочерние процессы |
| `peak_mb` | Максимум `rss_mb` за время работы |
| `cpu_pct` | Загрузка CPU процессом, % |
| `threads` | Число потоков |
| `connections` | Число сетевых соединений (`-1`, если системе не хватило прав его получить) |

При штатном завершении программы в конец файла добавляется строка `# peak_mb=...`.
Каждая строка пишется сразу, поэтому при аварийном завершении (например, `Killed` из-за нехватки памяти) отчёт сохраняется до последнего замера.

## Настройки

Параметры `start()` или переменные окружения:

| Параметр | Переменная | По умолчанию | Смысл |
|---|---|---|---|
| `interval` | `MEMMON_INTERVAL` | `10` | Интервал замера **в секундах** |
| `path` | `MEMMON_FILE` | `memmon_<PID>.csv` | Куда писать отчёт |
| `children` | нет | `True` | Учитывать память дочерних процессов |
| `trace` | `MEMMON_TRACE=1` | выкл. | Подробная трассировка через `tracemalloc` |

Пример установки переменной в PowerShell:

```
$env:MEMMON_INTERVAL = "5"
python -m memmon main.py
```

В Linux и macOS: `MEMMON_INTERVAL=5 python -m memmon main.py`.

Рекомендации по интервалу: 2-5 секунд для коротких нагрузочных тестов, 60-300 секунд для долгой работы.

## Режим трассировки (MEMMON_TRACE=1)

Показывает, в каких местах кода накапливаются объекты: сравнивает снимки памяти между замерами и пишет рост в файл `<отчёт>.trace.txt`.
Этот режим замедляет программу и сам расходует память, поэтому **цифры RAM в режиме трассировки завышены**. Для выбора хостинга замеряй без него, а трассировку включай только для поиска утечки.

## Как оценить нужный объём RAM для хостинга

1. Запусти программу под монитором без `MEMMON_TRACE` и под реалистичной нагрузкой.
2. Возьми максимум из `peak_mb`.
3. Добавь запас 30-50%: хостинг убивает процесс по пику, а не по среднему.

Для проверки сайта под нагрузкой используй отдельный инструмент (например, `locust`). `memmon` фиксирует реакцию программы, но нагрузку не создаёт.

## Ограничения

- Только Python-программы.
- Монитор работает, пока жива программа (поток фоновый и завершается вместе с ней). Чтобы отключить, уберите импорт или запускайте без `python -m memmon`.
- Если у проекта несколько процессов (например, воркеры gunicorn), импортируйте `memmon` в каждом: файлы создаются отдельно на каждый PID, суммировать их нужно самостоятельно.
- Подсчёт соединений на macOS и в некоторых системах может требовать повышенных прав, тогда в колонке будет `-1`.
- Базовая работа проверена на Linux (установка и запись замеров). На Windows и macOS проверь на своём примере.

## Переименование

Чтобы сменить название, замени его в трёх местах:

1. Имя внутренней папки с кодом (`memmon/memmon/`): от него зависит команда `import`.
2. Строка `name = "memmon"` в `pyproject.toml`.
3. Все `import memmon` в `auto.py` и `__main__.py`, а также команду `python -m memmon`.
